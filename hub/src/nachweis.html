Nachweis prüfen

Für Jugendwarte. Ein Kind zeigt dir seinen Code, wenn es alle Abzeichen eines Spiels zusammenhat. Vornamen und Code eintragen — der Rest steht dann hier.

Was der Code sagt — und was nicht

Er gehört zum Vornamen. Weitergeben nützt nichts: Toms Code gilt nur zu „Tom“. Wer mit fremdem Namen ankommt, fällt hier durch.

Der Name steht ab dem ersten Abzeichen fest. Ändern geht nur noch, indem man den ganzen Fortschritt zurücksetzt und von vorne anfängt. Ein fertiges Kind kann also niemandem eben schnell einen Code ausstellen.

Er beweist nicht, wer gespielt hat. Wer sich mit der Entwicklerkonsole auskennt, kann seinen Spielstand fälschen. Dagegen hilft kein Code, sondern eine Frage: Lass dir die Abzeichentafel zeigen und frag zu einem Abzeichen nach. Dort steht auch, wann jedes einzelne fiel.
